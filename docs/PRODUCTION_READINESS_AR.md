## 4. تقييم الجاهزية — لكل نظام فرعي

| النظام الفرعي | الجاهزية | الفجوة الحاسمة |
| --- | --- | --- |
| عقد السكريبت (validation) | 90% | لا يوجد منادٍ في الإنتاج: الوحيد الذي يستدعيه هو سكربت benchmark |
| الهوية اللونية (look) | 80% | `assets/luts/` فارغ؛ التدرّج كله فلاتر FFmpeg، لا LUT سينمائي |
| الرندر | 85% | لا دعم انتقالات (dissolve/wipe)، لا b-roll overlays |
| الكابشن | 60% | cue لكل مقطع، **لا مزامنة كلمة-بكلمة**؛ لا دعم عربي (reshaping غير موصول) |
| بوابات الجودة | 75% | motion/rhythm/exposure موجودة؛ لا فحص WER للصوت، لا فحص black frames لكل إطار |
| الصوت | 35% | لا TTS، لا مكتبة موسيقى، لا SFX؛ الميكس يعمل لكن على مسارات مُدخلة يدوياً |
| مصادر الفوتاج | 15% | لا Pexels/Reactor؛ الـ pipeline يستقبل مسارات محلية فقط |
| التنسيق (orchestrator) | 0% | لا Prefect flow، لا CLI `produce` |
| التسليم (Telegram) | 0% | لا عميل، لا موافقات بشرية |
| البحث والأفكار | 0% | لا شيء |
| CI/CD للإنتاج | 40% | workflow تجريبي واحد أضفته؛ لا نشر تلقائي |

**التقييم الإجمالي: ~38% جاهز للإنتاج.** المحرك السينمائي جاهز تقنياً؛ ما قبله (فكرة/نص/صوت/فوتاج) وما بعده (تسليم) غير موجود.

## 5. العوائق الصلبة (مرتبة بالأثر)

1. **لا صلاحية كتابة على المستودع** — كل أوامر الدفع والـ API ترجع 403. لا شيء من العمل الحالي محفوظ على GitHub.
2. **لا مصدر فوتاج** — بدون `PEXELS_API_KEY` لا يوجد إلا ما توفّره من ملفات. هذا وحده يمنع أي إنتاج حقيقي.
3. **لا صوت** — فيديو بلا تعليق صوتي = فيديو صامت بكابشن. غير قابل للنشر في هذا النيتش.
4. **لا جسر من السكريبت إلى اللقطات** — `validation.py` ينتج تقريراً نصياً، ولا شيء يحوّله إلى `beats` للـ EDL.
5. **النص إنجليزي** (`language: en` في الهوية) — إن كان الجمهور عربياً فهذا قرار استراتيجي يجب حسمه الآن، لأنه يغيّر الخط والاتجاه والـ TTS.

## 6. خطة الإنتاج الاحترافي — خطوة بخطوة

### المرحلة 0 — التمكين (30 دقيقة منك)
1. صلاحية الكتابة: تطبيق OpenHands على المستودع بـ **Contents: Read and write** + **Workflows: Read and write**.
2. الأسرار: `PEXELS_API_KEY`, `GEMINI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_OWNER_CHAT_ID`.
   - Pexels: مجاني من pexels.com/api — دقيقة واحدة.
   - Gemini: من aistudio.google.com — مجاني بحدود يومية كافية لـ 8 فيديوهات أسبوعياً.

### المرحلة 1 — الفوتاج الحقيقي (أعلى أثر، ~200 سطر)
- `engine/media/stock.py`: بحث Pexels بالكلمات + فلترة (المدة ≥ 6s، 1080p+، اتجاه عمودي/أفقي) + تنزيل + قياس `mean_luma` (الدالة موجودة).
- ربطه بـ `allocate.py` بدل الملفات المحلية.
- **المخرَج:** 30-50 مقطعاً حقيقياً مصنّفاً بالوسوم لكل فيديو.

### المرحلة 2 — الصوت أولاً، ثم المونتاج عليه (~250 سطر)
- `engine/audio/tts.py`: Gemini TTS لكل مشهد (كما في `voices.yaml`)، حفظ WAV + مدد حقيقية.
- **قاعدة حاكمة:** مدة اللقطة = مدة الجملة المنطوقة، لا العكس. هذا وحده يفرق بين "فيديو AI" و"فيديو احترافي".
- الكابشن يصبح word-level عبر WhisperX أو عبر توقيتات TTS.

### المرحلة 3 — جسر السكريبت → EDL (~150 سطر)
- `beats` تُشتق من `script.beats` الموجود في العقد (الحقول موجودة في `validation.py`) بدل beats مكتوبة يدوياً.

### المرحلة 4 — التشغيل والتسليم (~250 سطر)
- `orchestrator/produce.py`: topic → script → beats → stock → EDL → gates → render → preview → Telegram.
- `.github/workflows/produce.yml`: زر واحد من الهاتف.
- الموافقات الخمس المعلنة في `quality_gates.yaml` تُرسل كأزرار تيليجرام.

### المرحلة 5 — المعايرة البصرية (مستمرة)
- LUT حقيقي لكل حساب في `assets/luts/` بدل الفلاتر اليدوية.
- خط عربي (Noto Naskh) + `arabic-reshaper` + `python-bidi` إن كان الجمهور عربياً.
- مكتبة موسيقى (3-5 مسارات لكل حساب) + SFX.

**التقدير:** المراحل 1-4 = 4 جلسات عمل مركّزة. بعدها فيديو واحد كل 6-8 دقائق حوسبة.

## 8. المخاطر

1. **مخاطر الجودة:** فوتاج Pexels عام ومتشابه؛ التميّز سيأتي من النص والصوت لا من الصورة. بدون TTS ممتاز، النتيجة "سلايد شو فوتاج" بمستوى متوسط.
2. **مخاطر المنصة:** الفيديوهات المتشابهة بين حسابين قد تُصنّف تكراراً. الفصل اللوني والنصي موجود (`look` + DNA) لكن يجب اختبار عملي.
3. **مخاطر تقنية:** كل الحوسبة في Actions تعني 6-8 دقائق لكل فيديو؛ Kaggle أفضل للتوليد الثقيل (Wan I2V موجود كتجربة في `gate-scenes-kaggle.yml`).
4. **مخاطر تشغيلية:** لا شيء محفوظ على GitHub حتى الآن — العمل الحالي في بيئة واحدة فقط.

## 9. الحكم النهائي

- **هل ينتج فيديو؟** نعم، على هذا الفرع، بجودة تقنية سليمة (1080×1920، صوت مُعاير، كابشن محروق، بوابات خضراء).
- **هل هو جاهز للإنتاج؟** **لا.** المحرك جاهز؛ السلسلة حوله غير موجودة.
- **ما أول شيء يجب فعله؟** صلاحية الكتابة، ثم `PEXELS_API_KEY` + `GEMINI_API_KEY`. أي عمل قبل ذلك يبقى في بيئة واحدة بلا أثر.
